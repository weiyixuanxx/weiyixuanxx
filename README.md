## 🚀 项目经历

### 🤖 RAG PDF 智能阅读助手

基于 **Retrieval-Augmented Generation（RAG）** 构建的 PDF 智能阅读与问答系统。

主要实现：

* PDF 文档解析与文本切分
* 文本向量化与向量检索
* 基于检索结果进行 LLM 问答
* 构建完整 RAG Pipeline

**技术栈：**

`Python` `LLM` `RAG` `Embedding` `Vector Retrieval`

👉 [查看项目](https://github.com/weiyixuanxx/RAG-pdf)

---

### 🕵️ Mini Sniffer — 网络流量分析工具

使用 **Python + Scapy** 实现的轻量级网络抓包与协议分析工具。

主要功能：

* 实时网络数据包捕获
* TCP / UDP / ICMP 等协议解析
* DNS 与应用层协议分析
* 网络流量统计
* 图形化用户界面
* 支持打包为独立桌面程序

**技术栈：**

`Python` `Scapy` `Computer Network` `Tkinter`

👉 [查看项目](https://github.com/weiyixuanxx/sniffer)

---

### 👁 Vision Transformer 图像分类

基于 **Vision Transformer（ViT）** 完成 CIFAR-10 图像分类实验，并对 Transformer 在计算机视觉任务中的应用进行学习与实践。

主要内容：

* Vision Transformer 模型实现
* CIFAR-10 数据处理
* 模型训练与评估
* 深度学习实验结果分析

**技术栈：**

`Python` `PyTorch` `Vision Transformer` `Deep Learning`

👉 [查看项目](https://github.com/weiyixuanxx/VIT-cifar10-UCAS)
